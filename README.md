### 💊 PharmaHouse

Conceito de aplicação para facilitar a **compra e entrega de medicamentos através de farmácias**.

**Tecnologias:**

`React` `JavaScript` `Node.js` `MySQL`

🔗 **[Código no GitHub](https://github.com/antonio-atp/pharma-house)**
